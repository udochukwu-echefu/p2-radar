What it does
Projects

Know which work exists only on this computer.

Every git repo in your home folder, sorted by how exposed it is. Snapshot, push, or back up to a private GitHub repo. Back up all does every local-only project at once.

Cleanup

Free space without guessing.

Downloads, Desktop and storage, sorted for you. Only what's safe is pre-ticked: installers for apps you have, duplicates, caches that rebuild themselves. Everything goes to the Trash or Recycle Bin, with undo.

Secrets

Catch the key before it ships.

Finds credential files that git tracks, would commit next, or that sit loose in your folders. Stop tracking removes them from git and adds them to .gitignore.

Convert

Any document, one click.

Drop a file or pick a recent one. Word, RTF, Markdown, HTML, PDF and images, converted with tools already on your computer (on Windows, Word or LibreOffice for documents). The result lands next to the original. Jump anywhere with Ctrl K.

How it works

Three small parts. All on your computer.

SWIFT · C#

The app

Window, menu bar or tray, notifications and file watching. Native on Mac and Windows.

127.0.0.1

Local server

The dashboard talks to the engine on your computer only, with a per-launch token for every action.

PYTHON

Engine

Scans repos with git, sorts folders, checks for secrets. Standard library only.

Download P2 Radar
Download

Get P2 Radar for your computer.

macOS
  • macOS 14 or later, Apple silicon and Intel
  • Needs Python 3 (macOS offers to install it)
  • First open: if macOS blocks it, go to System Settings › Privacy & Security and click Open Anyway
Download for Mac
Windows
  • Windows 10 or 11, 64-bit
  • Needs Python 3 from python.org
  • Unzip and open "P2 Radar.exe". If SmartScreen warns, click More info › Run anyway
