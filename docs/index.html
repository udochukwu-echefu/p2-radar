How it works

Inside Radar

[NATIVE],[LOCAL],[OPEN SOURCE]
  • Mac app[SWIFT]

    Window, menu bar, notifications and file watching. Converts documents with macOS's text system and PDFKit.

  • Engine[PYTHON]

    Scans repos with git, sorts folders, checks for secrets. Standard library only, nothing to install.

  • Local server[127.0.0.1]

    The dashboard talks to the engine on your Mac only, with a per-launch token for every action.

  • Trash, never delete[UNDO]

    Every sweep is logged, so the last batch can always be put back until you empty the Trash.
